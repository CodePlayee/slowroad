# Additional woodland species

Geometry generated offline using @dgreenheck/ez-tree 1.1.0 (MIT; see EZ-TREE-LICENSE). Rebuild with `node gauntlet/bake-species.mjs`; that file retains the seeded branch and leaf parameters.

Birch and aspen use the library birch bark and aspen leaf cutout. Maple is a broad-crowned deciduous interpretation using the ash branch preset and existing oak leaf cutout, not a botanically exact maple leaf model. Spruce uses a low-branching dense evergreen architecture and the existing pine needle cutout. Existing bark/needle maps and their sources remain documented in BARK-SOURCES.md and BARK-README.md. Birch bark is sourced by EZ-Tree from TextureCan (CC0; https://www.texturecan.com/details/221/ and https://www.texturecan.com/terms/). The leaf cutout is distributed with EZ-Tree under MIT.

All parts retain positions, normals and UVs. Every full crown is rooted at y=0 and normalized to height=1. No tree generator or texture synthesis runs in the game.
