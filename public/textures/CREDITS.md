The 1K diffuse maps are used as world-space surface detail with seasonal tinting.

## Meadow Opacity R31

`meadow-opacity-r31.png` was generated with the built-in image generation tool.
The only style reference was `refs/slowroads/official/sr_01.jpg`. It is an RGB
opacity mask used by Three.js `alphaMap`, not an image with an alpha channel.
The original rejected checkerboard preview is not used by the application.
Prompts and generation provenance: `meadow-opacity-r31.md`.

## Meadow Turf V1

`meadow-turf-v1.png` is an original texture generated with the built-in image
generation tool on 2026-09-19, not a Poly Haven or Slow Roads asset. It replaces
the leafy-grass detail source in the active terrain material. The existing
forest-floor texture remains in use for litter. See `meadow-turf-v1.md`.
